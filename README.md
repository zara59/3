# Milestone Crowdfunding

A Solidity crowdfunding contract that allows a project creator to raise funds and release them through predefined milestones.

## Features

- Campaign funding
- Funding target
- Campaign deadline
- Contributor tracking
- Milestone-based fund releases
- Creator-only milestone releases
- Campaign cancellation
- Contributor refunds
- Custom errors
- Events
- Reentrancy protection
